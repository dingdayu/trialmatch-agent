## 1. 产品概述

### 1.1 产品背景

在临床研究中，受试者筛选是关键环节。CRC（临床研究协调员）和研究者需要手工对照研究方案的入选/排除标准，逐条审核受试者的病历、检查报告、检验结果等大量资料。该过程耗时、易出错，且缺乏系统化的证据追溯机制。

TrialMatch AI（研筛通）旨在通过 AI 技术，自动化完成受试者资料解析与入排标准匹配，提升筛选效率，确保判断可追溯，并保留人工复核流程以保障准确性。

### 1.2 产品定位

面向医院、CRO、临床研究机构的 **后台系统**，提供：

- 受试者资料上传与 AI 解析
- 入排标准逐条自动匹配
- 判断结果置信度评估与证据溯源
- 人工复核与改判机制

### 1.3 核心价值

| 价值维度     | 描述                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 效率提升     | AI 自动解析资料并匹配标准，将数小时的手工筛选缩短至分钟级               |
| 证据可追溯   | 每条判断均引用原始文件、页码及原文摘录，确保结论有据可查               |
| 人工可控     | 支持逐条人工复核与改判，AI 辅助而非替代人工决策                        |
| 标准化管理   | 项目级入排标准与 AI 提示词统一配置，保障多中心研究的一致性             |

### 1.4 产品目标

1. 将受试者初筛效率提升 **5 倍以上**。
2. AI 判断准确率达到 **85%+**（置信度 ≥ 80% 的判断）。
3. 实现 **100%** 判断结果可溯源至原始文件。
4. 支持单项目 **数百名受试者** 的并发筛选。

## 3. 核心业务流程

```
用户登录
  │
  ▼
进入项目列表 ──► 创建/选择项目
                    │
                    ▼
              项目配置（入排标准、AI 提示词、方案文件）
                    │
                    ▼
              进入受试者列表 ──► 新增受试者
                    │
                    ▼
              上传受试者素材（病例、报告等）
                    │
                    ▼
              启动 AI 初筛
                    │
                    ▼
         ┌──────────────────────────┐
         │  AI 文件解析              │
         │  → 受试者资料结构化       │
         │  → 逐条匹配入排标准       │
         │  → 生成判断 + 置信度      │
         │  → 关联证据引用           │
         └──────────────────────────┘
                    │
                    ▼
              查看匹配结果
                    │
              ┌─────┴─────┐
              │ 需人工复核？│
              └─────┬─────┘
               是 ↙    ↘ 否
         人工复核/改判    │
              │          │
              ▼          ▼
         确认初筛结论
              │
              ▼
         导出报告 / 归档
```

| 解析粒度 | 按页/片段（chunk）级别解析，支持页码定位                     |
| 抽取内容 | 原文内容、结构化实体（年龄、诊断、检验指标等）、页面坐标（可选） |
| 解析状态 | 等待中（pending）→ 解析中（parsing）→ 已解析（parsed）/ 失败（failed） |
| 业务规则 | 解析结果按片段存储，支持证据引用时精确定位到文件和页码       |

---

### 4.6 审计日志模块

| 项目     | 描述                                                         |
| -------- | ------------------------------------------------------------ |
| 功能描述 | 记录系统中关键操作的审计日志                                 |
| 记录范围 | 人工修改判断结果、重新分析、文件删除/上传、项目配置变更、用户登录 |
| 记录字段 | 操作人、操作类型、操作对象、变更前值、变更后值、操作时间     |
| 业务规则 | 日志不可删除、不可篡改；仅管理员可查看                       |
