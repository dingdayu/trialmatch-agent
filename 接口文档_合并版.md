# TrialMatch AI（研筛通）统一接口文档

| 字段       | 内容                                         |
| ---------- | -------------------------------------------- |
| 产品名称   | TrialMatch AI / 研筛通                       |
| 文档版本   | v1.1                                         |
| 创建日期   | 2026-06-27                                   |
| 基础路径   | `/api/v1`                                    |
| 协议       | HTTP / HTTPS                                 |
| 数据格式   | JSON（`Content-Type: application/json`）      |
| 文件上传   | `multipart/form-data`                        |
| 认证方式   | Bearer Token（JWT）                          |

---

## 1. 通用约定

### 1.1 请求规范

- 除登录接口外，所有接口需在请求头中携带 JWT 令牌：

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

- 文件上传接口使用 `Content-Type: multipart/form-data`。
- 时间字段统一使用 ISO 8601 格式（UTC）：`2026-06-27T10:30:00Z`
- ID 字段统一使用 UUID v4 格式。
- 分页参数统一使用 `page`（页码，从 1 开始）和 `page_size`（每页条数，默认 20，最大 100）。

### 1.2 统一响应格式

#### 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "request_id": "req_202606270001"
}
```

#### 分页响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [ ... ],
    "total": 100,
    "page": 1,
    "page_size": 20
  },
  "request_id": "req_202606270002"
}
```

#### 错误响应

```json
{
  "code": 40001,
  "message": "请求参数错误",
  "data": null,
  "request_id": "req_202606270003"
}
```

### 1.3 全局错误码

| code  | HTTP 状态码 | 说明                         |
| ----: | ----------- | ---------------------------- |
|     0 | 200/201/202 | 成功                         |
| 40001 | 400         | 请求参数错误                 |
| 40002 | 400         | 数据校验失败                 |
| 40101 | 401         | 未登录或 Token 无效          |
| 40102 | 401         | Token 已过期                 |
| 40103 | 401         | 用户名或密码错误             |
| 40301 | 403         | 无权限执行此操作             |
| 40302 | 403         | 账号已禁用                   |
| 40303 | 423         | 账号已锁定（连续输错 5 次）  |
| 40401 | 404         | 资源不存在                   |
| 40901 | 409         | 数据冲突（编号重复等）       |
| 40902 | 409         | 数据依赖冲突（有关联数据）   |
| 42901 | 429         | 请求频率超限                 |
| 50001 | 500         | 服务器内部错误               |
| 50002 | 502         | AI 服务不可用                |
| 50003 | 500         | 文件解析失败                 |
| 50301 | 503         | 服务暂不可用                 |

## 2. 枚举定义

### 2.1 用户角色 (role)

| 值              | 说明         |
| --------------- | ------------ |
| admin           | 系统管理员   |
| project_manager | 项目管理员   |
| crc             | 研究协调员   |
| viewer          | 只读用户     |

### 2.2 用户状态 (user_status)

| 值       | 说明   |
| -------- | ------ |
| active   | 正常   |
| disabled | 已禁用 |

### 2.3 项目状态 (project_status)

| 值          | 说明   |
| ----------- | ------ |
| draft       | 草稿   |
| configuring | 配置中 |
| screening   | 筛选中 |
| paused      | 已暂停 |
| completed   | 已完成 |

### 2.4 标准类型 (criterion_type)

| 值        | 说明     |
| --------- | -------- |
| inclusion | 入选标准 |
| exclusion | 排除标准 |

### 2.5 受试者初筛状态 (screening_status)

| 值          | 说明       |
| ----------- | ---------- |
| not_started | 未开始     |
| parsing     | 解析中     |
| matching    | 匹配中     |
| need_review | 待人工确认 |
| completed   | 已完成     |
| failed      | 失败       |

### 2.6 总体初筛结论 (overall_result)

| 值                | 说明       |
| ----------------- | ---------- |
| recommended       | 建议入组   |
| excluded          | 疑似排除   |
| insufficient_data | 资料不足   |
| manual_review     | 需人工确认 |

### 2.7 AI 判断结果 (ai_result)

**入选标准：**

| 值                | 说明     |
| ----------------- | -------- |
| pass              | 通过     |
| fail              | 不通过   |
| insufficient_data | 资料不足 |
| manual_review     | 需人工确认 |

**排除标准：**

| 值                | 说明       |
| ----------------- | ---------- |
| exclusion_hit     | 命中排除   |
| exclusion_not_hit | 未命中排除 |
| insufficient_data | 资料不足   |
| manual_review     | 需人工确认 |

### 2.8 人工复核状态 (review_status)

| 值          | 说明       |
| ----------- | ---------- |
| unconfirmed | 未确认     |
| confirmed   | 已确认     |
| overridden  | 已改判     |

### 2.9 文件类型 (file_type)

| 值                | 说明       |
| ----------------- | ---------- |
| protocol          | 项目方案   |
| medical_record    | 病例       |
| lab_report        | 检验报告   |
| exam_report       | 检查报告   |
| imaging_report    | 影像报告   |
| pathology_report  | 病理报告   |
| discharge_summary | 出院记录   |
| informed_consent  | 知情同意   |
| other             | 其他       |

### 2.10 文件归属 (file_scope)

| 值               | 说明         |
| ---------------- | ------------ |
| subject_data     | 受试者资料   |
| project_protocol | 项目方案文件 |

### 2.11 文件解析状态 (parse_status)

| 值      | 说明     |
| ------- | -------- |
| pending | 待解析   |
| parsing | 解析中   |
| parsed  | 已解析   |

### 2.12 AI 分析任务状态 (run_status)

| 值        | 说明   |
| --------- | ------ |
